# Screenshots

The plugin catalog's pictures, made by `bun scripts/screenshots.ts` (harness running): its dark tour takes them at
1440x900 with mock reviewers, named as seats on real profiles are: no "(mock)", no mock chip. The catalog links them at a release tag, so take them again before a release when the view
changes.

- `workspace.png`: four reviewers investigating on their own, with the process strip and the findings coming in.
- `council.png`: the deliberation, each finding backed or challenged with evidence, round by round.
- `ruling.png`: the verdict's action plan and a disputed finding's minority report, ready to accept, dismiss or defer.
