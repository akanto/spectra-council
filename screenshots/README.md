# Screenshots

The pictures of the plugin's page in Mirador's Plugins…, made by `bun scripts/screenshots.ts` (harness running): its dark tour takes them at
1440x900 with mock reviewers, named as seats on real profiles are: no "(mock)", no mock chip. `plugin.json` lists them with their captions,
and Mirador's plugin catalog links them at each release tag, so take them again before a release when the view changes.

- `workspace.png`: four reviewers investigating on their own, with the process strip and the findings coming in.
- `council.png`: the deliberation, each finding backed or challenged with evidence, round by round.
- `ruling.png`: the verdict's action plan and a disputed finding's minority report, ready to accept, dismiss or defer.
